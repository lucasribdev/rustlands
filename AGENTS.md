# Repository instructions

## Language preference

Use English for all new or modified project text, including player-facing strings,
documentation, comments, commit messages, and pull request descriptions. Communicate
with the user in English as well, even when their request is written in Portuguese,
unless they explicitly request another language. Apply this preference in future
sessions working in this repository. Preserve localization keys and prototype IDs
when translating text; do not translate unrelated upstream localization files.
